# GameBalanceConfig 快速上手步骤

## ⚡ 5分钟搭建完成

### 第一步：创建配置文件夹（如果没有）
1. 在 `Assets/` 下创建文件夹 `Settings` 或 `Config`
2. 用于存放游戏配置资源

---

### 第二步：创建配置资源
1. 在Project窗口中，右键点击 `Settings` 文件夹
2. 选择 **`Create > Game > Balance Config`**
3. 命名为 **`GameBalanceConfig_V1_测试`**

![创建配置](https://i.imgur.com/placeholder.png)

---

### 第三步：检查配置数值
1. 选中刚创建的 `GameBalanceConfig_V1_测试`
2. 在Inspector中会看到所有配置字段
3. **默认数值已经填好**，你可以直接使用！

#### 你会看到：
- ✅ 一天长度: 600秒 (10分钟)
- ✅ 饱食下降: 0.25点/秒
- ✅ 食物恢复: 40点
- ✅ 翻桶冷却: 150秒
- ✅ ...以及更多

#### Inspector底部会显示：
- 📊 **理论数据计算**（自动显示）
- ⚠️ **自动警告**（如果配置不合理）
- 🎨 **快速预设按钮**（轻松/标准/挑战）

---

### 第四步：在场景中使用
1. 打开你的 `SandBox.unity` 场景
2. 找到或创建 `GameManager` 对象（如果已有就直接用）
3. 添加 **`GameBalance`** 组件：
   - 选中GameManager
   - 点击 `Add Component`
   - 搜索 `GameBalance`
   - 添加
4. 将 `GameBalanceConfig_V1_测试` **拖入** `config` 字段

![配置引用](https://i.imgur.com/placeholder2.png)

---

### 第五步：在脚本中使用（示例）

#### 方法1：修改现有的SurvivalStats.cs

找到你的 `Assets/Scripts/Survival/SurvivalStats.cs`，替换硬编码数值：

**修改前:**
```csharp
public float maxHunger = 100f;
public float hungerDecreaseRate = 10f; // 每分钟
```

**修改后:**
```csharp
// 不需要这些字段了，直接从配置读取
private void Start()
{
    currentHunger = GameBalance.Config.maxHunger;
    currentHealth = GameBalance.Config.maxHealth;
}

private void Update()
{
    // 使用配置的下降速度
    currentHunger -= GameBalance.Config.hungerDrainPerSecond * Time.deltaTime;
}
```

#### 方法2：修改TrashBin.cs

在翻垃圾桶时使用配置：

```csharp
// 使用配置的读条时间
yield return new WaitForSeconds(GameBalance.Config.binSearchTime);

// 使用配置的风险检查
if (GameBalance.Config.RollBinRisk())
{
    player.TakeDamage(GameBalance.Config.binRiskDamage);
}

// 使用配置的掉落数量
int lootCount = GameBalance.Config.GetBinLootCount();
```

---

### 第六步：测试！

1. 点击 **Play** 运行游戏
2. 观察Console，应该看到：
   ```
   [GameBalance] 配置加载完成 - 一天长度: 600秒
   ```
3. 开始测试你的游戏！

## 🎛️ 如果需要调整

### 感觉太轻松？
1. 选中配置文件
2. 在Inspector底部点击 **"挑战模式"** 按钮
3. 或者手动调整：
   - `hungerDrainPerSecond` 改成 `0.3`
   - `foodRestoreAmount` 改成 `35`

### 感觉太紧张？
1. 点击 **"轻松模式"** 按钮
2. 或者手动调整：
   - `hungerDrainPerSecond` 改成 `0.2`
   - `foodRestoreAmount` 改成 `50`

### 想加速测试？
- 将 `timeScale` 改成 `2.0`（两倍速）
- 快速测试多天循环

## 🆘 遇到问题？

### 错误："未找到GameBalanceConfig"
**原因**: 场景中没有GameBalance组件，或config字段未配置  
**解决**: 检查步骤四

### 错误："Config为空"
**原因**: 配置文件未正确拖入  
**解决**: 确保在场景中的GameBalance组件上能看到配置文件的引用

### 配置修改了但没生效
**原因**: 可能在运行时修改（运行时修改不保存）  
**解决**: 停止游戏运行，再修改配置文件
