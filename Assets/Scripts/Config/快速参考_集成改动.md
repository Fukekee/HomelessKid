## 🎮 新功能：运行时调试面板

### RuntimeDebugPanel.cs
**功能**:
- 按 F1 切换显示/隐藏
- 实时调整所有关键配置参数
- 显示理论数据计算
- 快速预设切换（轻松/标准/困难）

**支持的参数**:
- 时间系统（2个参数）
- 饱食度系统（2个参数）
- 健康度系统（3个参数）
- 垃圾桶系统（2个参数）
- 地面垃圾系统（2个参数）

**注意**: UI 需要在 Unity 编辑器中手动创建和配置
