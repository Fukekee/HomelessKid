## 🚀 立刻开始使用（3步）

### 第1步：创建配置资源（30秒）
1. Project窗口右键
2. `Create > Game > Balance Config`
3. 命名为 `GameBalanceConfig_V1_测试`

### 第2步：添加到场景（30秒）
1. 选择场景中的GameManager（或创建一个）
2. `Add Component > GameBalance`
3. 拖入配置文件到 `config` 字段

### 第3步：运行测试（即刻）
1. 点击Play运行
2. Console应显示：`[GameBalance] 配置加载完成 - 一天长度: 600秒`
3. 开始测试！

**详细步骤**: 阅读 `快速上手步骤.md`

## 💡 使用技巧

### 快速查看配置摘要
```
选中场景中的GameBalance组件
右键菜单 > 显示配置摘要
```

### 加速测试多天循环
```
配置文件中 timeScale 改成 2.0
10分钟变5分钟，快速验证
```

### 开启调试模式
```
勾选 showDebugInfo
Console会显示更多信息
```

### 测试无敌模式
```
勾选 godMode
在代码中检查：
if (!GameBalance.Config.godMode) {
    // 扣减数值
}
```

## ⚠️ 重要注意事项

### ❗ 必须做的
1. **在场景中添加GameBalance组件**
   - 否则代码访问会报空
   
2. **配置文件要在非运行时修改**
   - 运行时修改不保存
   
3. **先测试再修改**
   - 不要边测边改数值

### 💡 建议做的
1. **创建多个配置文件**
   - 轻松、标准、挑战各一个
   
2. **记录每次测试**
   - 使用测试记录模板
   
3. **关注Inspector警告**
   - 黄色/红色提示要注意
