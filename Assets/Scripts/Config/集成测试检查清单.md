## 🧪 系统集成测试

### 1. SurvivalStats 系统测试

#### 测试步骤
1. 运行游戏
2. 观察 Console 输出是否有 `[SurvivalStats] 已从 GameBalanceConfig 加载配置`
3. 等待一段时间，观察饱食度是否按配置速率下降（每秒 0.25 点）
4. 使用食物（如果有），观察是否恢复 40 点饱食度

#### 验证点
- [ ] 系统成功加载配置（Console 有日志）
- [ ] 饱食度下降速率正确（约每分钟 15 点）
- [ ] 食物恢复量正确（40 点）
- [ ] 无错误或警告信息

#### 预期行为
- 饱食度从 100 开始，约 6.5 分钟降到 0
- 吃一份食物恢复 40 点，可支撑约 2.5 分钟

---

### 2. DayManager 系统测试

#### 测试步骤
1. 运行游戏
2. 观察 Console 输出是否有 `[DayManager] 已从 GameBalanceConfig 加载配置 - 一天长度: 600秒`
3. 观察时间 UI 的变化速度
4. 修改配置中的 timeScale 为 2.0，重新运行，观察时间是否加速

#### 验证点
- [ ] 系统成功加载配置（Console 有日志）
- [ ] 一天长度为 600 秒（10 分钟）
- [ ] 时间倍率生效（修改后时间流速改变）
- [ ] 无错误或警告信息

#### 预期行为
- 正常情况下，10 分钟（600 秒）完成一天
- timeScale = 2.0 时，5 分钟完成一天

---

### 3. TrashBin 系统测试

#### 测试步骤
1. 运行游戏
2. 观察 Console 输出是否有 `[TrashBin] 已从 GameBalanceConfig 加载配置`
3. 找到垃圾桶并交互（按 E）
4. 观察读条时间是否为 2.5 秒
5. 观察是否有概率受到伤害（15% 概率，10 点伤害）
6. 再次尝试翻同一个垃圾桶，观察是否有 150 秒冷却

#### 验证点
- [ ] 系统成功加载配置（Console 有日志）
- [ ] 翻桶读条时间为 2.5 秒
- [ ] 风险概率约为 15%（多次测试）
- [ ] 受伤时损失 10 点健康度
- [ ] 冷却时间为 150 秒（2.5 分钟）
- [ ] 掉落物品数量在 2-4 个之间
- [ ] 无错误或警告信息

#### 预期行为
- 翻桶需要 2.5 秒读条
- 约 15% 概率受伤（-10 健康度）
- 同一桶 2.5 分钟后才能再次翻找
- 每次掉落 2-4 个物品

---

### 4. TrashSpawner 系统测试

#### 测试步骤
1. 运行游戏
2. 观察 Console 输出是否有 `[TrashSpawner] 已从 GameBalanceConfig 加载配置`
3. 观察场景中生成的地面垃圾数量
4. 查看 Console 日志，确认生成数量在 8-12 个之间
5. 回到基地睡觉，进入新一天
6. 观察是否重新生成垃圾

#### 验证点
- [ ] 系统成功加载配置（Console 有日志）
- [ ] 每天生成的垃圾数量在 8-12 个之间
- [ ] 新一天开始时会清除旧垃圾并生成新垃圾
- [ ] Console 显示生成数量（如 `生成了 10 个垃圾`）
- [ ] 无错误或警告信息

#### 预期行为
- 第一天开始时生成 8-12 个随机垃圾
- 每天重新生成，数量随机
- 旧垃圾会被清除

## 🎮 运行时调试面板测试

### 5. RuntimeDebugPanel 功能测试

#### 测试步骤
1. 运行游戏
2. 按 **F1** 键，观察调试面板是否显示
3. 再按 **F1**，观察面板是否隐藏
4. 显示面板后，尝试拖动滑块修改参数
5. 观察右侧理论数据是否实时更新
6. 点击"轻松模式"预设按钮
7. 观察所有参数是否切换到轻松模式数值
8. 在游戏中验证修改是否生效（如饱食度下降速度）

#### 验证点
- [ ] F1 键可以切换面板显示/隐藏
- [ ] 滑块可以调整参数
- [ ] 输入框可以输入精确数值
- [ ] 理论数据实时更新
- [ ] 预设按钮正常工作
- [ ] 参数修改立即生效
- [ ] 无错误或警告信息

#### 预期行为
- 按 F1 显示/隐藏调试面板
- 修改参数后游戏系统立即响应
- 理论数据根据当前配置实时计算显示
- 预设按钮一键切换难度
