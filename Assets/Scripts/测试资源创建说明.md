# 测试资源创建说明

## 任务9-10：创建测试用Stage数据资源和建筑材料ItemData

以下资源需要在Unity编辑器中手动创建。

---

## 步骤1：创建建筑材料ItemData

### 1.1 创建木板（WoodBoard）

1. 在Project窗口中，右键点击 `Assets/ART/` 文件夹（或创建 `Assets/Items/` 文件夹）
2. 选择 `Create > Game > Item Data`
3. 命名为 `ItemData_WoodBoard`
4. 在Inspector中配置：
   - **itemName**: "木板"
   - **itemType**: `BuildingMaterial`
   - **value**: `5`
   - **isUsable**: `false`
   - **description**: "可以用来建造基地的材料"

### 1.2 创建布（Cloth）

1. 同样方式创建 `ItemData_Cloth`
2. 在Inspector中配置：
   - **itemName**: "布"
   - **itemType**: `BuildingMaterial`
   - **value**: `3`
   - **isUsable**: `false`
   - **description**: "可以用来建造基地的材料"

---

## 步骤2：创建基地Stage数据资源

### 2.1 创建Stage 0数据（无家/露宿）

1. 在Project窗口中，右键点击 `Assets/` 文件夹（或创建 `Assets/Shelter/` 文件夹）
2. 选择 `Create > Game > Shelter Stage Data`
3. 命名为 `ShelterStageData_Stage0`
4. 在Inspector中配置：
   - **stageId**: `0`
   - **stageName**: "无家/露宿"
   - **requiredMaterials**: 留空（初始阶段不需要材料）
   - **healthRecoveryMultiplier**: `1.0`
   - **moodRecoveryMultiplier**: `1.0`
   - **moodBaseBonus**: `0`
   - **description**: "初始状态，没有固定的住所"

### 2.2 创建Stage 1数据（废棚子角落）

1. 同样方式创建 `ShelterStageData_Stage1`
2. 在Inspector中配置：
   - **stageId**: `1`
   - **stageName**: "废棚子角落"
   - **requiredMaterials**: 
     - 点击 `+` 添加第一个材料
       - **item**: 拖入 `ItemData_WoodBoard`
       - **amount**: `3`
     - 点击 `+` 添加第二个材料
       - **item**: 拖入 `ItemData_Cloth`
       - **amount**: `2`
   - **healthRecoveryMultiplier**: `1.2`
   - **moodRecoveryMultiplier**: `1.3`
   - **moodBaseBonus**: `10`
   - **description**: "用木板和布搭建的简陋角落，至少能遮风挡雨"

---

## 步骤3：在场景中配置Shelter

1. 打开 `SandBox.unity` 场景
2. 找到场景中的 `Shelter` GameObject
3. 在Inspector中找到 `Shelter` 组件
4. 在 `Stage Data List` 中：
   - 设置 `Size` 为 `2`
   - `Element 0`: 拖入 `ShelterStageData_Stage0`
   - `Element 1`: 拖入 `ShelterStageData_Stage1`

---

## 步骤4：配置升级UI（可选）

如果要在SleepPanel中显示升级功能：

1. 找到场景中的 `SleepPanel` GameObject
2. 添加 `ShelterUpgradeUI` 组件
3. 在Inspector中配置：
   - **Upgrade Button**: 拖入升级按钮（需要在SleepPanel中创建）
   - **Upgrade Info Text**: 拖入显示升级信息的Text组件
   - **Materials Text**: 拖入显示材料需求的Text组件

---

## 步骤5：配置SurvivalUI显示Mood

1. 找到场景中的 `SurvivalUI` GameObject
2. 在Inspector中找到 `SurvivalUI` 组件
3. 配置新的字段：
   - **Mood Text**: 创建或拖入一个TextMeshProUGUI组件显示mood数值
   - **Mood Slider**: 创建或拖入一个Slider组件显示mood百分比条

---

## 测试验证

完成以上步骤后，运行游戏测试：

1. **Mood系统**：
   - [ ] mood数值正确显示在UI
   - [ ] 夜晚在外时mood下降（等待到夜晚或调整时间）
   - [ ] 在基地睡觉时mood恢复

2. **基地升级**：
   - [ ] 收集足够的材料（木板x3, 布x2）
   - [ ] 进入小屋，点击升级按钮
   - [ ] 升级成功，材料被消耗
   - [ ] 升级后恢复倍率生效
   - [ ] 升级时mood一次性增加10点

3. **时间系统**：
   - [ ] 一天长度为15分钟（900秒）
   - [ ] 夜晚判断正确（21:00-06:00）

## 如何控制木板、布的出现概率

### 1. 地面垃圾（每天刷在地上的可拾取物）

在场景里选中 **TrashSpawner**，使用 **Weighted Trash Pool（加权物品池）**：

- 点击 `+` 添加一项，**Item** 拖入 `ItemData_木板`，**Weight** 填 `3`（数字越大越容易刷出）
- 再添加一项，**Item** 拖入 `ItemData_布`，**Weight** 填 `1`
- 这样木板出现概率约为 3/(3+1)=75%，布约为 25%。按需调整权重即可。

若继续使用旧的 **Trash Item Pool**（不加权），则每个物品在列表里出现几次，概率就按比例来（例如列表里 3 个木板、1 个布 → 75% 木板、25% 布）。

### 2. 翻垃圾桶（TrashBin）掉落

在场景里选中每个 **TrashBin**，在 **Drop Table** 里：

- 添加一项：**Item** = 木板，**Drop Chance** = `0.5`（50% 概率掉）
- 再添加一项：**Item** = 布，**Drop Chance** = `0.3`（30% 概率掉）
- 每次翻桶会按掉落数量先抽几次，每抽一次按表里的顺序和各自的 Drop Chance 决定是否掉该物品。

调高/调低对应物品的 **Drop Chance**（0～1）即可控制木板、布在翻桶时的出现概率。

## 获得物品提示（翻桶/拾取地面垃圾）

只要背包成功添加物品（翻桶、拾取地面垃圾、商店购买等），会统一弹出「获得了：xxx」的提示。

**场景配置：**

1. 在 Canvas 下新建一个 **Panel**（如命名为 `ItemObtainedPanel`），作为提示容器。
2. 在该 Panel 下放一个 **TextMeshPro - Text**，写默认文案如「获得了：木板」（运行时会由代码替换）。
3. 选中场景中的 **UIManager** 所在物体，在 Inspector 的 **获得物品提示** 区域：
   - **Item Obtained Panel**：拖入上面的 `ItemObtainedPanel`
   - **Item Obtained Text**：拖入该 Panel 下的 TMP 文本
   - **Item Obtained Display Duration**：提示显示秒数（默认 2 秒）
4. 若 **Item Obtained Panel** 或 **Item Obtained Text** 留空，则不会显示获得提示（不影响其他功能）。

---

## 注意事项

1. 确保所有ItemData的itemType设置为 `BuildingMaterial`
2. 确保Shelter的Stage Data List按stageId顺序排列
3. 如果升级UI不显示，检查SleepPanel是否激活了ShelterUpgradeUI组件
4. 如果mood不下降，检查：
   - DayManager是否正确判断夜晚
   - SurvivalStats的isInShelter标记是否正确设置
   - 玩家是否真的在基地外
