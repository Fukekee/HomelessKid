# Unity灰盒原型场景设置指南

本文档说明如何在Unity编辑器中设置SandBox.unity场景以实现完整的游戏功能。

## 1. 玩家设置

### 1.1 创建玩家GameObject
1. 创建空的GameObject，命名为"Player"
2. 添加以下组件：
   - `CharacterController` (Unity组件)
   - `PlayerMovementController` (我们的脚本)
   - `SurvivalStats` (生存系统)
   - `Inventory` (背包系统)
   - `InteractionManager` (交互管理器)

### 1.2 设置CharacterController
- 调整CharacterController的Height和Radius以适合玩家
- 确保Step Offset设置合理

### 1.3 创建摄像机
1. 在Player下创建子对象"Camera"或"Main Camera"
2. 添加`Camera`组件
3. 添加`PlayerCameraController`脚本
4. 调整摄像机位置（例如：Position Y = 1.6，模拟眼睛高度）

### 1.4 设置Tag和Layer
- 确保Player GameObject的Tag设置为"Player"
- 创建一个"Player"层，并将Player GameObject设置为此层

## 2. UI Canvas设置

### 2.1 创建主Canvas
1. 创建Canvas (UI > Canvas)
2. 设置为"Screen Space - Overlay"

### 2.2 生存数值UI
在Canvas下创建：
- **HungerUI**: Text或Slider显示饱食度
  - 添加`SurvivalUI`脚本
  - 配置hungerText和hungerSlider引用

- **HealthUI**: Text或Slider显示健康度
  - 在SurvivalUI脚本中配置healthText和healthSlider引用

### 2.3 天数UI
- **DayUI**: Text显示当前天数
  - 添加`DayUI`脚本
  - 配置dayText引用

### 2.4 交互提示UI
- **InteractionPrompt**: Text显示交互提示
  - 将其引用到InteractionManager的interactionPromptText字段

### 2.5 进度条UI（用于垃圾桶翻找）
- 创建Panel命名为"ProgressBarPanel"
  - 添加Slider子对象
  - 初始设置为非激活
  - 在UIManager中配置引用

### 2.6 背包UI
创建Panel命名为"InventoryPanel"：
- 添加`InventoryUI`脚本
- 创建ScrollView用于显示物品列表
- 创建ItemSlot预制体（包含Text和Button）
- 配置InventoryUI的引用

### 2.7 兑换站UI
创建Panel命名为"ExchangePanel"：
- 添加物品列表容器
- 添加货币显示Text
- 添加关闭按钮
- 在ExchangeStation中配置引用

### 2.8 商店UI
创建Panel命名为"ShopPanel"：
- 添加商品列表容器
- 添加货币显示Text
- 添加关闭按钮
- 在Shop中配置引用

### 2.9 小屋UI
创建Panel命名为"SleepPanel"：
- 添加"睡觉"按钮
- 添加"取消"按钮
- 在Shelter中配置引用

## 3. 场景对象设置

### 3.1 地面
- 使用现有Prefab（如Demo_Asphalt）或创建Plane作为地面
- 确保有Collider

### 3.2 垃圾生成点
1. 创建空的GameObject命名为"TrashSpawner"
2. 添加`TrashSpawner`脚本
3. 创建多个空的子GameObject作为生成点（命名为SpawnPoint_1, SpawnPoint_2等）
4. 将这些Transform添加到TrashSpawner的spawnPoints列表

### 3.3 地面垃圾预制体
1. 创建一个简单的GameObject（如Cube或Sphere）命名为"GroundTrashPrefab"
2. 添加Collider
3. 添加`GroundTrash`脚本
4. 保存为Prefab
5. 将Prefab引用到TrashSpawner的groundTrashPrefab字段

### 3.4 垃圾桶
1. 创建GameObject命名为"TrashBin"（可以使用Cube等简单几何体）
2. 添加Collider
3. 添加`TrashBin`脚本
4. 配置掉落表（TrashDrop列表）
5. 在场景中放置多个垃圾桶

### 3.5 小屋/过夜点
1. 创建GameObject命名为"Shelter"（可以使用Cube作为占位符）
2. 添加Collider（设置为Trigger）
3. 添加`Shelter`脚本
4. 配置UI引用

### 3.6 兑换站
1. 创建GameObject命名为"ExchangeStation"
2. 添加Collider
3. 添加`ExchangeStation`脚本
4. 配置UI引用

### 3.7 商店
1. 创建GameObject命名为"Shop"
2. 添加Collider
3. 添加`Shop`脚本
4. 配置商品列表（ShopItem列表）
5. 配置UI引用

## 4. 管理器设置

### 4.1 GameManager
1. 创建空的GameObject命名为"GameManager"
2. 添加`GameManager`脚本
3. 设置初始货币数量

### 4.2 DayManager
1. 创建空的GameObject命名为"DayManager"
2. 添加`DayManager`脚本
3. 配置一天时长（默认600秒=10分钟）

### 4.3 UIManager
1. 在Canvas或场景根目录创建GameObject命名为"UIManager"
2. 添加`UIManager`脚本
3. 配置所有UI引用

## 5. 物品数据创建

### 5.1 创建ItemData ScriptableObject
1. 在Project窗口中右键：Create > Game > Item Data
2. 创建以下物品：
   - **食物类**（如：面包、苹果）- isUsable = true, hungerRestore > 0
   - **材料类**（如：塑料瓶、纸箱）- value > 0
   - **杂物类**（如：垃圾袋、废纸）- value较小

### 5.2 配置垃圾池
- 在TrashSpawner的trashItemPool中添加可生成的垃圾物品
- 在TrashBin的dropTable中配置掉落物品及其概率

### 5.3 配置商店商品
- 在Shop的shopItems中配置可购买的商品及其价格

## 6. 图层设置

建议创建以下图层：
- Player
- Interactable
- Ground

并配置InteractionManager的interactionLayer掩码。

## 注意事项

1. 确保所有GameObject都有正确的Tag和Layer设置
2. UI Canvas应该设置为Screen Space - Overlay以确保始终可见
3. 所有Collider应该正确配置，交互对象需要有Collider
4. 物品数据（ItemData）需要提前创建好
5. 场景中的位置需要手动调整以适应游戏体验
