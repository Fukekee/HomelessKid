# 草莓河运小镇 · 完整物品清单

> 本文档包含游戏中所有可拾取物品的完整属性，包括普通物品、不洁物品和特殊剧情物品。  
> 可直接用于 Unity ScriptableObject 配置或 Excel 数据表导入。

## 一、物品属性字段说明

| 字段 | 说明 | 类型 |
|------|------|------|
| ItemID | 物品唯一标识符 | string |
| 物品名称 | 显示名称 | string |
| 物品类型 | Food(食物) / Material(材料) / Junk(杂物) | enum |

## 四、特殊机制说明

### 4.1 不洁物品的处理方式

1. **拾取惩罚**：所有不洁物品在拾取时立即扣除健康值
2. **持有惩罚**：持有不洁物品期间，每小时持续扣除健康值
3. **净化机制**（可选）：
   - 使用"晾晒架"晾晒可降低风险（减少持有惩罚）
   - 使用"小炉位"加热可完全净化（移除unsafe标签，但价值降低）
   - 交给特定NPC（如守墓人）可获得奖励并移除风险

### 4.2 情绪物品的特殊效果

- 带有 `emotional` 标签的物品在拾取时提升心情值
- 某些情绪物品可触发NPC对话或剧情任务
- 家族物品（ANCESTOR系列）可大幅提升心情，是主角身份认同的关键

### 4.3 高价值物品的交易建议

- 带有 `high_value` 标签的物品建议出售给特定NPC
- 不洁物品虽然价值高，但需要权衡健康风险
- 某些高价值物品保留后可用于建造高级模块

## 六、Unity 数据表导入建议

### 6.1 扩展 ItemData ScriptableObject

建议在现有 `ItemData.cs` 基础上添加以下字段：

```csharp
[Header("区域与稀有度")]
public string sourceRegion = ""; // 来源区域
public Rarity rarity = Rarity.Common; // 稀有度

[Header("标签系统")]
public List<ItemTag> tags = new List<ItemTag>(); // 物品标签

[Header("数值影响")]
public int healthEffect = 0; // 健康影响
public int moodEffect = 0; // 心情影响

[Header("不洁物品特殊属性")]
public bool isUnsafe = false; // 是否为不洁物品
public int unsafeHealthPenalty = 0; // 拾取时健康惩罚
public int unsafeHourlyPenalty = 0; // 持有期间每小时惩罚

[Header("描述")]
[TextArea(2, 4)]
public string systemDescription = ""; // 系统描述
[TextArea(2, 4)]
public string childPerspective = ""; // 主角视角描述
```

### 6.2 枚举定义

```csharp
public enum Rarity
{
    Common,     // 普通
    Uncommon,   // 少见
    Rare,       // 稀有
    Unique      // 唯一
}

public enum ItemTag
{
    Unsafe,         // 不洁
    Emotional,      // 情绪
    HighValue,      // 高价值
    Buildable,      // 可建造
    Food,           // 食物
    Material,       // 材料
    Junk            // 杂物
}
```

## 七、策划备注

1. **不洁物品的平衡**：高价值但高风险，鼓励玩家做出选择
2. **情绪物品的重要性**：在生存压力下，情绪物品是维持mood的关键
3. **区域特色**：每个区域的物品都有明确的用途和情绪色彩
4. **季节系统**：通过季节变化让玩家感受到时间的流逝
5. **唯一物品**：家族物品和某些剧情物品不可再生，增加收集价值
